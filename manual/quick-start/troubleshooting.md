# 常見問題排查

遇到問題？本頁列出常見情況與解決方案。

## 無法啟用輸入法

### Android

**問題：** 在系統設定中找不到萱姆輸入法

**解決方案：**

1. 確認應用已安裝：前往 **設定** → **應用** → 搜尋「LIME」
2. 如果未安裝，重新下載並安裝 APK
3. 重啟手機
4. 重新進入 **設定** → **語言與輸入法** 找尋 **萱姆輸入法**

**如果仍未出現：**

1. 在 **設定** → **應用** 中找到 LIME
2. 點選並確認應用未禁用
3. 清除應用快取：**設定** → **應用** → **LIME** → **儲存空間** → **清除快取**
4. 重啟應用與手機

---

### iOS & iPad

**問題：** 新增鍵盤後找不到萱姆輸入法

**解決方案：**

1. 進入 **設定** → **一般** → **鍵盤** → **鍵盤**
2. 確認 **萱姆輸入法** 已列出
3. 如未出現，點選 **新增鍵盤** 後搜尋「LIME」或「萱姆」
4. 選擇 **萱姆輸入法** 並確認

**提示：** iOS 要求「完整取用」權限。在鍵盤列表中點選 **萱姆輸入法** 並開啟 **允許完整取用**。

---

## 輸入法已啟用，但無法切換到萱姆

### Android

**問題：** 在 IME 切換列表中看不到萱姆輸入法

**解決方案：**

1. 長按空白鍵或點選鍵盤左下角的切換鍵盤圖示
2. 會彈出 IME 清單，確認 **萱姆輸入法** 已列出
3. 如未列出，進入 **設定** → **語言與輸入法** → 啟用萱姆
4. 返回並重試

**無法長按空白鍵？**

某些手機可能不支援此快捷方式：

1. 點選 **設定** → **語言與輸入法** → **目前輸入法** → 選擇 **萱姆輸入法**

---

### iOS & iPad

**問題：** 長按地球圖示後看不到萱姆輸入法

**解決方案：**

1. 確認已在 **設定** → **一般** → **鍵盤** → **鍵盤** 中新增萱姆
2. 確認已允許 **完整取用** 權限
3. 重啟設定應用或重啟手機
4. 再次長按地球圖示（輸入法切換鍵）

---

## 按鍵震動無效

### Android 13+

**問題：** 按鍵沒有震動反饋

**解決方案：**

1. **啟用系統震動：**
   - 進入 **設定** → **聲音與震動** → **震動強度**
   - 調高震動強度（不要設為 0%）

2. **在 LIME 應用中啟用：**
   - 開啟 LIME 設定應用
   - 進入 **外觀** 或 **喜好設定** → **按鍵震動**
   - 確認開啟

3. **重啟手機後重試**

> **注意：** Android 13+ 的震動由系統統一控制，LIME 已移除單獨的震動強度設定。

---

## 無法下載或匯入輸入法

### 下載失敗

**問題：** 應用內下載輸入法時出錯

**解決方案：**

1. **檢查網路：**
   - 確保已連接 WiFi 或行動網路
   - 嘗試在其他應用中開啟網頁確認網路可用

2. **重試下載：**
   - 關閉應用
   - 等待 10 秒
   - 重新開啟應用並重試

3. **手動匯入：**
   - 如果應用內下載失敗，改用 [手動匯入](../ime-management/import-ime.md)

### 匯入失敗

**問題：** 無法匯入 .cin 或 .lime 檔案

**解決方案：**

1. **確認檔案格式：**
   - 檔案副檔名必須是 `.cin`、`.lime` 或 `.limedb`
   - 檔案應使用 UTF-8 編碼

2. **檢查檔案位置：**
   - 確保檔案儲存在可存取的位置（例如下載資料夾）

3. **重試匯入：**
   - 在 LIME 應用中選擇 **輸入法管理** → **匯入輸入法**
   - 選擇正確的檔案

詳見 [匯入輸入法](../ime-management/import-ime.md)。

## 候選列或輸入無反應

### Android

**問題：** 點選候選字或按鍵時無反應

**解決方案：**

1. **重啟應用：**
   - 切換到其他應用再切回
   - 重啟手機

2. **清除應用快取：**
   - 前往 **設定** → **應用** → **LIME** → **儲存空間** → **清除快取**

3. **重新安裝：**
   - 卸載應用
   - 重新下載並安裝最新版本

### iOS & iPad

**問題：** 鍵盤無反應或候選列未顯示

**解決方案：**

1. **隱藏並重新顯示鍵盤：**
   - 點選 return 或點選文字外的位置隱藏鍵盤
   - 再次點選文字欄位顯示鍵盤

2. **重啟應用：**
   - 切換應用後再切回
   - 重啟手機

3. **檢查「完整取用」：**
   - 進入 **設定** → **一般** → **鍵盤** → **LIME**
   - 確認 **允許完整取用** 已開啟
