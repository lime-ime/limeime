# 下載第一個輸入法

萱姆輸入法本身只是框架，你需要選擇一個輸入法才能開始輸入。

## 支援的輸入法

| 輸入法 | 適合使用者 | 說明 |
|------|---------|------|
| **注音（ㄓㄨㄥ）** | 台灣使用者 | 最常用、易學易用 |
| **倉頡** | 香港、大陸使用者 | 快速、適合手寫 |
| **大易** | 進階使用者 | 極快速輸入 |
| **嘸蟲蛇** | 形音混合愛好者 | 形音結合 |
| **其他** | 特定需求 | 詳見 [所有支援的輸入法](../ime-management/ime-list.md) |

## 如何下載輸入法

### 方法 1：應用內下載（推薦）

1. 開啟 **萱姆輸入法** 應用
2. 進入 **輸入法管理** 或 **Settings** → **輸入法列表**
3. 點選 **+ 下載** 或 **新增輸入法**
4. 選擇你要的輸入法（例如 **注音**）
5. 點選 **下載** 或 **安裝**

等待下載完成後，該輸入法會出現在你的輸入法列表。

> **網路提示：** 確保你的裝置已連接到 WiFi 或行動網路。輸入法檔案通常 1–5 MB。

### 方法 2：手動匯入

如果應用內下載無法使用，你可以手動匯入：

1. 從 [LIME IME 官方倉庫](https://github.com/lime-ime/limeime) 下載 `.cin` 或 `.lime` 檔案
2. 在應用中選擇 **匯入輸入法**
3. 選擇下載的檔案
4. 輸入法會被新增到列表

詳見 [匯入輸入法](../ime-management/import-ime.md)。

## 第一次使用建議

### 如果你在台灣
**推薦：注音（標準）**

注音是台灣最常見的輸入法，容易學習。

```
ㄓ ㄨ ㄥ + ㄧ ㄣ = 輸入中文
```

### 如果你在香港或大陸
**推薦：倉頡**

倉頡是香港和大陸常用的輸入法。

```
人手十 = 手
```

### 如果你想快速輸入
**推薦：大易**

大易需要學習，但非常快。

## 開始輸入

輸入法下載後：

1. 在任何文字欄位點選並喚出鍵盤
2. 開始按鍵盤按鍵輸入
3. 候選字會在鍵盤上方顯示
4. 點選候選字或按數字鍵選擇
