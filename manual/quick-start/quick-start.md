# 快速設定

3 分鐘快速上手萱姆輸入法。

## Android

### 第 1 步：下載應用

1. 前往 [GitHub Releases](https://github.com/lime-ime/limeime/releases)
2. 下載最新版本的 APK（例如 `LIMEHD2026-6.1.15.apk`）
3. 安裝應用

### 第 2 步：啟用輸入法

1. 開啟 **系統設定** → **語言與輸入法**（或 **系統** → **語言與輸入法**）
2. 在「虛擬鍵盤」下找到 **萱姆輸入法** (LIME)
3. 點選 **萱姆輸入法** 並啟用

### 第 3 步：切換到萱姆

1. 在任何文字輸入欄位點選
2. 長按空白鍵或點選切換鍵盤圖示
3. 選擇 **萱姆輸入法**

**完成！** 你現在可以開始輸入。詳見 [下載第一個輸入法](first-ime.md)。

> **提示：** 如果看不到萱姆輸入法，請確認已啟用。某些手機可能需要進入 **設定** → **應用** → 找到 LIME 應用，並確保有輸入法權限。

---

## iOS & iPad

### 第 1 步：下載應用

1. 在 App Store 搜尋「萱姆輸入法」或「LIME」
2. 點選 **下載** 並用 Apple ID 登入
3. 應用會自動安裝

### 第 2 步：新增鍵盤

1. 開啟 **設定** → **一般** → **鍵盤**
2. 點選 **鍵盤**（或 **新增鍵盤**）
3. 選擇 **萱姆輸入法**
4. 點選並開啟 **允許完整取用**

> **重要：** iOS 要求用戶明確允許「完整取用」才能啟用鍵盤。

### 第 3 步：切換到萱姆

1. 在任何文字輸入欄位點選，喚出鍵盤
2. 長按地球圖示（輸入法切換鍵）
3. 選擇 **萱姆輸入法**

**完成！** 詳見 [下載第一個輸入法](first-ime.md)。

> **iPad 提示：** iPad 支援分割鍵盤與副鍵符號。詳見 [iPad 副鍵符號](../keyboard-layouts/ipad/secondary-glyphs.md)。
