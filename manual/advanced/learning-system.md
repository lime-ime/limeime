# 學習系統

LIME 自動學習機制的原理與最佳化。

## 什麼是自動學習？

自動學習是 LIME 根據你的輸入習慣自動調整候選字順序的功能。

**目標：** 你越常選某個字，它就越早出現在候選列中。

**示例：**

```
第一次輸入「中」：
編碼 ㄓ → 候選：[這] [中] [之] ...

選擇「中」 5 次，「中」出現 1 次後：

現在輸入「中」：
編碼 ㄓ → 候選：[中] [這] [之] ...
                ↑ 已上升至首位
```

## 學習如何運作

### 1. 記錄選擇

每當你選擇候選字時，LIME 記錄：

- **編碼** — 你輸入的鍵序列
- **字符** — 你選擇的字
- **時間戳** — 何時選擇
- **上下文** — 前後字符（可選）

### 2. 計算頻率

LIME 計算每個編碼-字符組合被選擇的次數：

```
ㄓ → 中: 15 次
ㄓ → 這: 3 次
ㄓ → 之: 1 次
```

### 3. 調整排序

根據頻率重新排序候選列：

```
高頻率 (15) → [中]
中頻率 (3)  → [這]
低頻率 (1)  → [之]
```

### 4. 持續改進

隨著更多輸入，頻率不斷更新，排序也動態調整。

## 學習速度設定

### 調整學習速率

進入 **喜好設定** → **輸入行為** → **學習速度**：

| 設定 | 說明 | 適用場景 |
|------|------|--------|
| **慢** | 需要多次選擇後才學習（10+ 次） | 審慎輸入，避免誤觸影響 |
| **正常** | 標準速度（3–5 次後開始調整） | 推薦（預設） |
| **快** | 立即學習（1–2 次後即調整） | 新手機，快速適應 |

### 新手推薦

**新手機遷移流程：**

1. 安裝 LIME 後設定學習速度為 **快**
2. 使用 2–3 周，建立個人輸入習慣
3. 改為 **正常**，穩定使用

## 詞句學習

### 詞句組合記憶

LIME 不只學習單字，也學習常用詞句：

```
選擇「中」→「文」：
記錄「中文」這個詞組

下次輸入「中」時：
候選列可能優先顯示「中文」而非單字「中」
```

### 個人語言風格

LIME 適應你的語言風格：

- **常用詞** — 「好的」vs「可以」
- **用語習慣** — 敬語 vs 口語
- **專業術語** — 如你經常輸入特定領域詞彙

**結果：** 輸入速度逐漸提升，候選字也越來越符合你的習慣。

## 上下文学習（進階）

### 什麼是上下文？

某些 LIME 版本支援記住字符前後的搭配：

```
「中國」的「中」頻率高
「中午」的「中」頻率高
「中文」的「中」頻率高

輸入「中」後，根據前一個字預測下一個字更相關
```

### 啟用上下文學習

進入 **喜好設定** → **輸入行為** → **上下文感知**：

- **關閉** — 不使用上下文
- **開啟** — 基於前一字預測
- **進階** — 基於前多個字預測（更耗電）

## 重置與優化學習

### 何時需要重置

在以下情況，你可能想重置學習資料：

1. **換輸入法** — 新輸入法從零開始
2. **切換用途** — 從工作切換到娛樂
3. **歷史污染** — 誤觸導致錯誤的字頻率高
4. **重新適應** — 改變輸入習慣

### 重置學習

**警告：** 此操作不可逆。

1. 進入 **設定** → **進階** → **清除學習歷史**
2. 選擇：
   - **當前輸入法** — 只重置此輸入法
   - **全部輸入法** — 重置所有
3. 確認刪除

### 部分清除

如果只想移除特定詞語的學習：

1. 進入 **輸入法管理** → **編輯**
2. 找到不想要的詞語
3. 選擇 **刪除** 或 **重設頻率**

## 學習統計

### 檢視學習進度

進入 **設定** → **進階** → **學習統計**：

- **學習項目數** — 已學習的編碼-字符組合
- **最常用字** — 頻率最高的字
- **最近輸入** — 最近使用的字詞
- **學習時間** — 從開始使用到現在的時長

## 最佳化學習效果

### 避免污染

學習資料可能被誤觸或測試污染：

**預防方法：**

1. 啟用 **長按時間** 調整，避免誤觸
2. 定期檢查 **最常用字**，確保符合習慣
3. 如發現異常，用 **編輯** 功能手動調整

### 加速適應

快速建立個人語言模型：

1. 設定學習速度為 **快**
2. 連續使用 1–2 周
3. 定期檢查學習結果
4. 改為 **正常** 維持

### 跨裝置同步

如果在多台裝置使用 LIME：

1. 在主裝置上充分使用（建立完整學習）
2. 備份主裝置的學習資料
3. 在新裝置上還原備份
4. 新裝置會繼承學習歷史

## 學習效能

### 對性能的影響

啟用學習會：

- **增加** CPU 使用率（通常 < 5%）
- **增加** 儲存空間（1–50 MB）
- **不影響** 輸入速度（有時加快）
- **不影響** 電池續航（影響微小）

### 禁用學習

如果受影響嚴重，可禁用自動學習：

進入 **喜好設定** → **輸入行為** → **自動學習** → **關閉**

> **代價：** 每次輸入候選字順序都相同，無法個人化。

## 常見問題

### Q: 學習為什麼有時不起作用？

**A:** 可能原因：

1. **學習已禁用** — 檢查設定中是否開啟
2. **學習速度設為慢** — 需要更多選擇
3. **輸入法不同** — 每個輸入法獨立學習
4. **資料庫已滿** — 極少見，清理快取可解決

### Q: 學習資料會同步到雲端嗎？

**A:** 預設不會。需要手動備份和還原。

### Q: 可以為不同應用設定不同學習嗎？

**A:** 不支援。LIME 對所有應用使用相同學習資料。

### Q: 如何匯入他人的學習資料？

**A:** 透過備份機制：

1. 他人備份他們的 LIME 資料
2. 你在備份時選擇 **合併**
3. 他人的學習資料會加入你的資料庫

## 進階主題

### 機器學習演算法

LIME 使用的學習演算法包括：

- **頻率統計** — 簡單計數法
- **時間衰減** — 最近輸入權重更高
- **上下文模型** — 考慮前後字符
- **適應性預測** — 動態調整模型

具體實現取決於 LIME 版本。
