# 自製輸入法

從零開始建立自訂輸入法。

> **進階主題：** 本指南適合有技術背景的使用者。一般使用者可使用 [輸入法編輯](../ime-management/ime-editor.md) 功能。

## 支援的格式

LIME 支援以下輸入法格式：

| 格式 | 副檔名 | 用途 | 難度 |
|------|------|------|------|
| **CIN** (Chewing) | `.cin` | 通用格式 | ⭐ 易 |
| **LIME** | `.lime` | LIME 專用壓縮格式 | ⭐⭐ 中等 |
| **LIME DB** | `.limedb` | LIME 資料庫格式 | ⭐⭐⭐ 難 |

推薦新手從 **CIN 格式** 開始。

## CIN 格式介紹

CIN 是通用的輸入法格式，被多個輸入法引擎支援。

### CIN 檔案結構

```
[Chewing Table]
CharDef BEGIN
key1 char1
key2 char2
...
CharDef END

[Data]
code1 char1 freq1
code2 char2 freq2
...
```

### 基本組成

1. **表頭** — 格式說明
2. **字典** — 編碼對應字符
3. **頻率** — 候選字顯示順序

## 建立簡單輸入法

### 步驟 1：準備文字編輯器

使用支援 UTF-8 編碼的文字編輯器：

- **Windows** — Notepad++、VS Code
- **Mac** — TextEdit（改為純文字模式）
- **Linux** — Vim、Gedit

> **重要：** 儲存為 **UTF-8 無 BOM** 格式。

### 步驟 2：撰寫表頭

```
[Chewing Table]
CHARSET = UTF-8
NAME = 我的輸入法
SERIAL_NUMBER = 1
SELKEY = 1234567890
[Data]
```

| 欄位 | 說明 | 範例 |
|------|------|------|
| **CHARSET** | 文字編碼 | UTF-8 |
| **NAME** | 輸入法名稱 | 我的輸入法 |
| **SERIAL_NUMBER** | 版本號 | 1 |
| **SELKEY** | 選字快捷鍵 | 1234567890 |

### 步驟 3：新增字典資料

在 `[Data]` 後新增編碼和字符：

```
[Data]
abc 愛 100
abd 安 90
abe 按 80
acd 蒙 70
```

**格式：** `編碼 字符 頻率`

- **編碼** — 輸入的鍵序列（字母或數字）
- **字符** — 對應的字符
- **頻率** — 數字，越大越優先顯示

### 步驟 4：測試輸入法

1. 儲存為 `.cin` 檔案（例如 `myime.cin`）
2. 在 LIME 應用中 **匯入輸入法**
3. 選擇你的 `.cin` 檔案
4. 測試輸入

## 進階功能

### 多字詞組

支援多字詞句：

```
[Data]
abc 愛 100
abc 愛好 95
abc 愛心 90
```

同一編碼可對應多個字或詞。

### 符號與特殊字符

```
[Data]
dot 。 100
comma ， 90
quote 「 80
```

### 多碼字符

某些字可用多種編碼輸入：

```
[Data]
abc 愛 100
aaa 愛 100
```

同一字可用 `abc` 或 `aaa` 輸入。

## 常見問題

### Q: 新增字後無法顯示

**A:** 檢查以下：

1. **檔案編碼** — 確保為 UTF-8（無 BOM）
2. **字符正確** — 字符是否可複製、可見
3. **頻率設定** — 嘗試增加頻率數值
4. **檔案格式** — 確保符合 CIN 格式

### Q: 編碼衝突怎麼辦？

**A:** 如果多個字共享編碼，頻率決定優先度：

```
abc 愛 100  ← 首選
abc 安 90   ← 第二
abc 案 80   ← 第三
```

### Q: 如何加入標點符號？

**A:** 新增為常規字符：

```
dot 。 100
comma ， 100
semi ； 100
```

### Q: 輸入法太大怎麼壓縮？

**A:** 使用 LIME 格式（`.lime`）可壓縮。需要轉換工具。

詳見 LIME 官方倉庫。

## 分享輸入法

如果你想分享自訂輸入法：

1. **測試充分** — 確保沒有錯誤
2. **文件齊全** — 準備說明文件
3. **上傳到倉庫** — 提交到 GitHub 或其他平台
4. **獲得反饋** — 持續改進
