# 輸入行為

自訂 LIME 的輸入預測、詞句與學習設定。

## 詞句預測

### 啟用詞句預測

1. 開啟 LIME 應用 → **喜好設定** → **輸入行為**
2. **詞句預測** → **開啟**

啟用後，LIME 會在候選列中顯示常用詞句。

### 預測準確度

設定 LIME 如何預測詞句：

1. 進入 **喜好設定** → **輸入行為** → **預測強度**
2. 選擇：
   - **弱** — 只預測最常用詞句
   - **中** — 標準預測（推薦）
   - **強** — 激進預測，包括不常見詞句

> **提示：** 預測強度越高，候選字越多但可能包含不相關詞句。

## 自動學習

LIME 會自動記住你的輸入習慣。

### 啟用學習

1. 進入 **喜好設定** → **輸入行為** → **自動學習**
2. **開啟**

開啟後，LIME 會：
- 記錄你常用的字與詞
- 調整候選列順序
- 加快輸入速度

### 學習敏感度

1. 進入 **喜好設定** → **輸入行為** → **學習速度**
2. 選擇：
   - **慢** — 需要多次選擇後才學習
   - **正常** — 標準學習速度
   - **快** — 立即調整候選順序

> **提示：** 在新手機上使用「快速」學習，習慣後改為「正常」。

## 個人字典

### 新增個人字

1. 輸入編碼後，在候選列中找到想要的字
2. 長按該字
3. 選擇 **新增到個人字典**
4. 或進入 **輸入法編輯** → **新增字**

### 刪除個人字

1. 進入 **輸入法編輯** → **個人字典**
2. 找到要刪除的字
3. 點選 **刪除** 或長按選擇刪除

### 個人字優先度

某些輸入法允許調整字的優先度：

1. 在 **個人字典** 中選擇字
2. 調整 **優先度** 或 **頻率**
3. 更高數值 = 更優先顯示

## 空白鍵行為

### 空白鍵功能

空白鍵在不同情況下有不同行為：

| 情況 | 預設行為 | 可自訂 |
|------|--------|------|
| 有候選字 | 選擇首個候選字 | ✓ 可改為下一個 |
| 無候選字 | 輸入空格 | ✓ 可改為其他 |
| 多頁候選 | 翻頁 | ✓ 可改為選字 |

### 自訂空白鍵

1. 進入 **喜好設定** → **輸入行為** → **空白鍵行為**
2. 選擇：
   - **選擇** — 選擇首個候選（推薦）
   - **翻頁** — 翻到下一頁
   - **空格** — 直接輸入空格

## 快速選擇

### 按數字鍵選擇

在候選列顯示時，按 **1–9** 快速選擇對應的候選字。

**啟用/禁用：**

1. 進入 **喜好設定** → **輸入行為** → **數字選擇**
2. **開啟/關閉**

> **提示：** 關閉此功能可避免誤觸數字時意外選字。

## 句號自動轉換

### 中文標點自動轉換

某些輸入法支援自動轉換英文標點為中文標點：

1. 進入 **喜好設定** → **輸入行為** → **自動標點**
2. 選擇：
   - **關閉** — 手動輸入標點
   - **標準** — 自動轉換常見標點
   - **全部** — 轉換所有標點

**範例（啟用自動標點）：**
```
輸入：Hello. World
顯示：Hello。World（自動轉換）
```

## 候選列翻頁

### 翻頁方式

設定如何翻頁查看更多候選字：

1. 進入 **喜好設定** → **輸入行為** → **翻頁方式**
2. 選擇：
   - **按鍵** — 使用專用翻頁鍵
   - **滑動** — 向左滑動翻頁
   - **數字** — 按 0 或特定鍵翻頁

## 長按時間

### 調整長按靈敏度

1. 進入 **喜好設定** → **輸入行為** → **長按時間**
2. 選擇：
   - **短** — 0.3 秒快速觸發
   - **正常** — 0.7 秒（推薦）
   - **長** — 1.0 秒慢速觸發

> **提示：** 經常誤觸迷你鍵盤？改為「長」。

## 組合鍵

### 啟用組合鍵

某些輸入法支援快速組合鍵（如 Shift + 某鍵）：

1. 進入 **喜好設定** → **輸入行為** → **組合鍵**
2. **開啟/關閉**

詳見具體輸入法文件。

## 平台差異

### Android

- 完整支援所有輸入行為設定
- 可自訂幾乎所有按鍵行為
- 支援進階學習調整

### iOS & iPad

- 基本輸入行為設定可用
- 部分設定由系統控制
- iPad 額外支援手勢自訂

## 行為快速參考

| 設定 | 選項 | 推薦值 |
|------|------|------|
| 詞句預測 | 開/關 | 開 |
| 預測強度 | 弱/中/強 | 中 |
| 自動學習 | 開/關 | 開 |
| 學習速度 | 慢/正常/快 | 正常 |
| 空白鍵行為 | 選擇/翻頁/空格 | 選擇 |
| 數字選擇 | 開/關 | 開 |
| 自動標點 | 關/標準/全部 | 標準 |
| 長按時間 | 短/正常/長 | 正常 |
