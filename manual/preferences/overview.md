# 喜好設定

本章節說明如何自訂萱姆輸入法的各項設定。

## 本章主題

1. **[概述](overview.md)** — 設定應用簡介
2. **[外觀設定](appearance.md)** — 主題、字體大小、視覺回饋
3. **[輸入行為](ime-behavior.md)** — 詞句預測、智慧輸入、學習設定
4. **[繁簡轉換](han-conversion.md)** — 繁體/簡體轉換設定
5. **[字根反查](reverse-lookup.md)** — 反查設定與使用方法
6. **[備份與還原](backup-restore.md)** — 匯出/匯入設定與資料

## 設定應用結構

萱姆輸入法的設定應用分為多個頁籤，方便按功能分類：

- **外觀** — 視覺設定
- **輸入行為** — 輸入習慣與預測
- **轉換** — 繁簡轉換、字根反查
- **備份** — 資料管理
- **進階** — 高級功能（見進階章節）

## 平台差異

某些設定在 Android、iOS、iPad 上可能不同。各章節會標注平台特定說明。
