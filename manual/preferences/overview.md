# 喜好設定

本章介紹 LIME 設定應用的結構與所有可用選項。

## 設定應用簡介

LIME 設定應用是自訂輸入法的中樞。透過設定應用，你可以調整：

- **外觀** — 主題、字體、回饋
- **輸入行為** — 預測、學習、空白鍵
- **轉換** — 繁簡轉換、字根反查
- **備份** — 匯出與匯入資料

## 設定應用結構

### Android

進入 LIME 應用後，主菜單包含：

```
LIME 應用
├── 輸入法管理
│   ├── 下載
│   ├── 匯入
│   └── 編輯
├── 喜好設定
│   ├── 外觀
│   ├── 輸入行為
│   ├── 轉換設定
│   ├── 備份與還原
│   └── 進階
└── 幫助與回饋
```

### iOS & iPad

iOS 設定結構類似，但透過應用內菜單或 iOS **設定** → **鍵盤** 存取：

```
LIME 應用
├── 輸入法管理
├── 設定
│   ├── 外觀
│   ├── 輸入行為
│   ├── 轉換設定
│   ├── 備份與還原
│   └── 進階
└── 關於
```

## 主要設定分類

### 1️⃣ 外觀設定

**控制視覺外觀與回饋。**

| 選項 | 說明 |
|------|------|
| 鍵盤主題 | 深色、淺色、彩色主題 |
| 字體大小 | 按鍵與候選列字體 |
| 按鍵間距 | 按鍵寬度與間距 |
| 鍵盤高度 | 鍵盤佔用空間 |
| 按鍵震動 | 觸覺回饋 |
| 按鍵聲音 | 聲音反饋 |
| 候選列位置 | 上方、下方或浮動 |

詳見 [外觀設定](appearance.md)。

### 2️⃣ 輸入行為

**控制輸入預測與學習。**

| 選項 | 說明 |
|------|------|
| 詞句預測 | 啟用/禁用預測 |
| 自動學習 | 記憶輸入習慣 |
| 空白鍵行為 | 選擇、翻頁或空格 |
| 數字選擇 | 按 1–9 選字 |
| 自動標點 | 英轉中標點 |
| 長按時間 | 調整長按靈敏度 |

詳見 [輸入行為](ime-behavior.md)。

### 3️⃣ 繁簡轉換

**轉換字符編碼。**

| 選項 | 說明 |
|------|------|
| 轉換模式 | 繁體、簡體或自動 |
| 轉換範圍 | 全部、常用或詞句 |

詳見 [繁簡轉換](han-conversion.md)。

### 4️⃣ 字根反查

**反向查詢不知道編碼的字。**

| 選項 | 說明 |
|------|------|
| 啟用反查 | 開/關 |
| 反查方式 | 注音、筆劃或拼音 |
| 快捷鍵 | 觸發反查的鍵 |
| 反查模式 | 單次或持續 |

詳見 [字根反查](reverse-lookup.md)。

### 5️⃣ 備份與還原

**保護與轉移資料。**

| 選項 | 說明 |
|------|------|
| 備份 | 匯出設定與輸入法 |
| 還原 | 匯入備份 |
| 自動備份 | 定期自動備份 |

詳見 [備份與還原](backup-restore.md)。

### 6️⃣ 進階設定

**進階功能與優化。**

| 選項 | 說明 |
|------|------|
| 清除快取 | 釋放儲存空間 |
| 檢查資料庫 | 修復損壞資料 |
| 清除學習 | 重置學習資料 |
| 最佳化資料庫 | 提升性能 |

詳見 [進階](../advanced/overview.md)。

## 快速設定指南

### 新使用者

**建議首次設定順序：**

1. **外觀** — 選擇主題、調整字體大小
2. **輸入行為** — 開啟自動學習
3. **下載輸入法** — 選擇注音或倉頡
4. **開始輸入** — 熟悉基本操作

### 進階使用者

**效能最佳化：**

1. **輸入行為** — 調整學習速度
2. **進階** — 清理快取、壓縮資料庫
3. **字根反查** — 啟用反查功能
4. **繁簡轉換** — 根據需要設定

### 多平台使用者

**跨裝置同步：**

1. 在主裝置進行完整設定
2. **備份** — 備份所有資料
3. 在新裝置 **還原** 備份
4. 新裝置即可使用相同設定

## 設定位置

### Android

通常位於：
```
系統設定 → 應用 → LIME → 應用設定（或直接開啟 LIME 應用）
```

### iOS & iPad

兩種方式存取：
```
方式 1：LIME 應用 → Settings
方式 2：系統設定 → 鍵盤 → LIME
```

## 設定同步

### 同步支援

LIME 目前**不支援自動雲端同步**。設定與學習資料僅在設定裝置上。

**跨裝置同步方案：**

1. **備份機制** — 手動備份後在新裝置還原
2. **手動轉移** — 複製設定檔案（進階用戶）

詳見 [備份與還原](backup-restore.md)。

## 設定重置

### 重置全部設定

**警告：** 此操作不可逆。

1. 進入 **進階** → **重置設定**
2. 確認重置
3. LIME 恢復到出廠設定

**用途：**
- 解決設定衝突
- 重新開始配置
- 故障排查

### 重置特定設定

也可只重置某部分：

1. 進入相應設定頁面
2. 尋找 **重置** 按鈕（如有）
3. 確認重置

## 設定檔案位置

### Android

設定儲存在：
```
/data/data/net.toload.main.hd2026/shared_prefs/lime_settings.xml
```

進階使用者可透過 ADB 或檔案管理器存取。

### iOS & iPad

設定儲存在應用沙箱中，通常無法直接存取。

## 故障排查

### 設定無法儲存

1. **檢查儲存空間** — 確保手機有足夠空間
2. **重啟應用** — 關閉並重新開啟 LIME
3. **重啟手機** — 清除暫時錯誤
4. **重置設定** — 最後手段

### 某些選項不可見

1. **輸入法不同** — 某些選項僅特定輸入法有
2. **版本過舊** — 升級 LIME 到最新版本
3. **平台限制** — iOS 上某些選項不可用
