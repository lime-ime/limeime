# 外觀設定

自訂萱姆輸入法的視覺外觀與回饋。

## 鍵盤主題

### 選擇主題

1. 開啟 LIME 應用
2. 進入 **喜好設定** → **外觀**
3. 選擇 **鍵盤主題**
4. 選擇喜歡的主題並應用

### 內建主題

萱姆提供多種內建主題：

| 主題 | 說明 | 適合 |
|------|------|------|
| **淺色** | 白底黑字 | 白天、省電 |
| **深色** | 黑底白字 | 夜間、OLED 屏 |
| **藍色** | 藍色調 | 現代風格 |
| **綠色** | 綠色調 | 護眼 |
| **紅色** | 紅色調 | 個性化 |
| **系統** | 跟隨系統設定 | 自動匹配 |

> **提示：** 使用深色主題可延長電池續航，特別是在 OLED 屏上。

## 字體大小

### 調整鍵盤字體

1. 進入 **喜好設定** → **外觀** → **字體大小**
2. 選擇：
   - **小** — 節省空間，適合快速打字
   - **正常** — 標準大小
   - **大** — 更易閱讀，適合弱視用戶

### 調整候選列字體

1. 進入 **喜好設定** → **外觀** → **候選列字體**
2. 選擇大小
3. 應用

## 按鍵間距與鍵盤高度

### 按鍵間距

1. 進入 **喜好設定** → **外觀** → **按鍵間距**
2. 調整滑塊：
   - **緊密** — 更多按鍵在螢幕上
   - **舒適** — 避免誤觸
   - **寬鬆** — 最大按鍵面積

### 鍵盤高度

1. 進入 **喜好設定** → **外觀** → **鍵盤高度**
2. 調整：
   - **矮** — 留出更多應用空間
   - **正常** — 平衡高度
   - **高** — 更易觸及

## 按鍵震動與聲音

### 按鍵震動（Android 13+）

> **注意：** Android 13 及以上版本的震動由系統統一控制。

1. 進入 LIME 設定 → **喜好設定** → **外觀** → **按鍵震動**
2. **開啟**：按鍵時手機震動

3. 調整系統設定：
   - 進入 **系統設定** → **聲音與震動** → **震動強度**
   - 提高震動強度

### 按鍵聲音

1. 進入 LIME 設定 → **喜好設定** → **外觀** → **按鍵聲音**
2. **開啟**：按鍵時播放音效

3. 調整系統音量：
   - 進入 **系統設定** → **聲音與震動** → **音量**
   - 調高媒體音量（某些機型）

> **提示：** 靜音模式下按鍵聲音可能被系統靜音。

## 候選列設定

### 候選列位置

1. 進入 **喜好設定** → **外觀** → **候選列位置**
2. 選擇：
   - **上方**（預設） — 在鍵盤上方
   - **下方** — 在鍵盤下方
   - **浮動** — 隨意位置

### 候選列樣式

1. 進入 **喜好設定** → **外觀** → **候選列樣式**
2. 選擇：
   - **橫排** — 水平顯示候選字
   - **直排** — 豎直顯示（傳統風格）
   - **彈出** — 浮動彈出

### 候選列透明度

1. 進入 **喜好設定** → **外觀** → **候選列透明度**
2. 調整：
   - **不透明** — 完全不透明
   - **半透明** — 能看見背後內容
   - **透明** — 高度透明

## 光標與預覽

### 顯示光標

1. 進入 **喜好設定** → **外觀** → **顯示光標**
2. **開啟**：顯示文字光標位置

### 輸入預覽

1. 進入 **喜好設定** → **外觀** → **輸入預覽**
2. **開啟**：顯示已輸入的編碼預覽

## 深色模式（iOS）

### 自動深色模式

在 iOS 13+ 上，LIME 可自動跟隨系統深色模式：

1. 進入 LIME 設定 → **喜好設定** → **外觀**
2. **深色模式** → **自動**

系統在夜間自動切換到深色主題。

## 無障礙設定

### 高對比模式

1. 進入 **喜好設定** → **外觀** → **高對比**
2. **開啟**：提高顏色對比度（適合弱視用戶）

### 放大鍵盤

1. 進入 **喜好設定** → **外觀** → **放大**
2. 選擇放大倍數

## 平台特定設定

### Android

- 支援自訂主題與顏色
- 支援按鍵邊框與樣式
- 支援背景圖片（部分主題）

### iOS & iPad

- 主題跟隨系統設定
- 無法自訂顏色
- iPad 額外支援分割鍵盤外觀

詳見 [iPad 副鍵符號](../keyboard-layouts/ipad/secondary-glyphs.md)。

## 外觀快速參考

| 設定 | 選項 | 預設 |
|------|------|------|
| 鍵盤主題 | 淺色/深色/彩色 | 系統 |
| 字體大小 | 小/正常/大 | 正常 |
| 按鍵間距 | 緊密/舒適/寬鬆 | 舒適 |
| 鍵盤高度 | 矮/正常/高 | 正常 |
| 按鍵震動 | 開/關 | 開 |
| 按鍵聲音 | 開/關 | 關 |
| 候選列位置 | 上/下/浮動 | 上 |
