# 備份與還原

匯出與匯入 LIME 的所有設定與資料。

## 備份用途

定期備份可保護：

- 自訂輸入法與字庫
- 個人詞句與短語
- 學習系統的輸入歷史
- 鍵盤佈局與主題設定
- 喜好設定與偏好

## 如何備份

### Android

1. 開啟 **萱姆輸入法** 應用
2. 進入 **喜好設定** → **備份與還原** → **備份**
3. 選擇備份位置：
   - **本機儲存** — 保存到 Downloads 資料夾
   - **Google Drive** — 儲存到雲端
   - **其他應用** — 如 Dropbox、OneDrive
4. 選擇備份範圍：
   - **全部** — 所有資料
   - **設定只** — 僅設定
   - **輸入法只** — 僅輸入法
5. 確認並等待備份完成

### iOS & iPad

1. 開啟 **萱姆輸入法** 應用
2. 進入 **設定** → **備份與還原** → **備份**
3. 選擇儲存位置：
   - **iCloud Drive** — 自動同步
   - **本機檔案應用** — 本機儲存
4. 確認備份

> **提示：** iOS 上備份自動加密。

## 如何還原

### Android

1. 開啟 LIME 應用
2. 進入 **喜好設定** → **備份與還原** → **還原**
3. 選擇備份檔案
4. 選擇還原範圍：
   - **全部** — 覆蓋所有資料
   - **合併** — 與現有資料合併
5. 確認並等待完成

> **警告：** 完全還原會覆蓋現有資料。如不確定，選擇「合併」。

### iOS & iPad

1. 開啟 LIME 應用
2. 進入 **設定** → **備份與還原** → **還原**
3. 選擇備份檔案
4. 確認還原

## 備份檔案

### 檔案格式

- **格式：** ZIP 壓縮檔案
- **副檔名：** `.zip` 或 `.limebackup`
- **大小：** 通常 1–20 MB（取決於資料量）

### 備份檔案內容

```
backup-2026-06-08.zip
├── settings.json        # 喜好設定
├── user-phrases.db      # 個人詞句
├── ime-data/            # 輸入法資料
│   ├── zhuyin.db
│   ├── cangjie.db
│   └── ...
├── learning/            # 學習資料
│   └── history.db
└── themes/              # 主題資料
    └── custom-theme.json
```

## 備份最佳實踐

### 定期備份

- **每月一次** — 最低標準
- **裝置更新前** — 重要時刻
- **重大設定變更後** — 保險起見
- **換新手機前** — 遷移資料

### 多處備份

不要只依賴單一備份：

1. **本機備份** — 儲存在手機本身
2. **雲端備份** — Google Drive、iCloud Drive
3. **電腦備份** — 用 USB 複製到電腦

### 備份命名規範

```
LIME-backup-2026-06-08.zip
LIME-backup-工作用.zip
LIME-backup-個人用.zip
```

清晰的名稱便於管理多個備份。

## 還原場景

### 場景 1：新手機遷移

1. 在舊手機上進行完整備份
2. 安裝 LIME 到新手機
3. 還原備份 → 「全部」
4. 所有設定與輸入法立即可用

### 場景 2：誤刪復原

1. 選擇最近的備份
2. 還原 → 「合併」（避免覆蓋新資料）
3. 檢查已刪除的資料是否復原

### 場景 3：清除垃圾

1. 備份當前狀態
2. 進入輸入法管理，刪除不用的輸入法
3. 刪除舊的自訂詞句
4. 進行新的備份（瘦身後的版本）

## 跨平台遷移

### Android → iOS

1. 在 Android 上備份
2. 下載備份檔案到電腦
3. 在 iOS 上還原：
   - 將檔案上傳到 iCloud Drive
   - 在 LIME 應用中選擇還原
4. 選擇檔案並完成

### iOS → Android

1. 在 iOS 上備份到 iCloud Drive
2. 在 Android 上進入 **備份與還原** → **還原**
3. 選擇 Google Drive 中的檔案
4. 完成還原

> **注意：** 跨平台遷移時某些平台特定設定可能遺失。

## 常見問題

### Q: 備份會佔用多少空間？

**A:** 一般 1–20 MB，取決於：
- 自訂輸入法數量
- 個人詞句數量
- 學習歷史大小

### Q: 備份需要多長時間？

**A:** 通常 30 秒至 2 分鐘，取決於資料量與儲存位置。

### Q: 備份檔案會過期嗎？

**A:** 不會。備份檔案永久有效，可任何時間還原。

### Q: 可以進行增量備份嗎？

**A:** LIME 目前進行完整備份。建議定期備份管理舊版本。

### Q: 備份檔案加密嗎？

**A:**
- **Android：** 否，檔案為開放式 ZIP
- **iOS：** 是，備份在 iCloud 上自動加密
