# 字根反查

反查不知道編碼的字符。

## 什麼是字根反查？

字根反查是一種「反向查詢」功能。當你知道字符的形狀或發音，但不知道輸入法的編碼時，可以用反查找到該字。

**場景：** 你想輸入「馬」字，但不記得倉頡編碼。用反查功能查詢。

## 反查方式

### 注音反查

使用注音符號反查倉頡、大易等輸入法中的字：

1. **激活反查** — 通常按 **Ctrl+Z** 或 **\** 或 **`**（取決於輸入法）
2. **輸入注音** — 按注音符號
3. **查詢結果** — 候選列顯示符合的字
4. **選擇** — 按數字選擇想要的字

**範例（在倉頡模式中反查）：**
```
要輸入「馬」但不知道倉頡編碼
按反查鍵 → 激活注音反查
輸入 ㄇ ㄚ → 候選列顯示「馬」等
按 1 → 「馬」被輸入
```

### 筆劃反查

某些輸入法支援按筆劃數反查：

1. **激活反查**
2. **輸入筆劃數** — 按 1–9 表示筆劃數
3. **選擇字** — 從候選列選擇

### 拼音反查

在簡體輸入法中，可用拼音反查：

1. **激活反查**
2. **輸入拼音** — 按對應拼音鍵
3. **查詢並選擇**

## 啟用反查功能

### Android

1. 開啟 LIME 應用 → **喜好設定** → **反查設定**
2. **啟用反查** → **開啟**
3. 選擇 **反查方式**：
   - 注音反查
   - 筆劃反查
   - 拼音反查

### iOS & iPad

1. 開啟 LIME 應用 → **設定** → **反查**
2. **啟用** → **開啟**
3. 選擇反查方式

## 設定反查快捷鍵

### Android

1. 進入 **喜好設定** → **反查設定** → **快捷鍵**
2. 選擇或自訂觸發鍵：
   - **\\** — 反斜線
   - **`** — 重音符
   - **Ctrl+Z** — Ctrl 組合
   - **自訂** — 自定義組合

### iOS & iPad

反查快捷鍵通常由系統決定，可選項有限。

## 反查範例

### 例 1：倉頡查馬字

```
當前輸入法：倉頡
要輸入：馬

步驟：
1. 按反查鍵（\\）
2. 輸入「ㄇ ㄚ」（注音）
3. 候選列顯示：馬 駕 媽 ...
4. 按 1 選擇「馬」
5. 「馬」被輸入到文字欄
```

### 例 2：大易查學字

```
當前輸入法：大易
要輸入：學

步驟：
1. 按反查鍵
2. 輸入「ㄒ ㄩㄝ」（注音）
3. 候選列顯示：學 校 ...
4. 選擇「學」
```

### 例 3：筆劃查木字

```
要查木字（4 筆）

步驟：
1. 按反查鍵
2. 輸入「4」（表示 4 筆畫）
3. 候選列顯示所有 4 筆的字
4. 尋找並選擇「木」
```

## 反查設定

### 反查模式

1. 進入 **喜好設定** → **反查設定** → **反查模式**
2. 選擇：
   - **單次** — 反查後自動退出
   - **持續** — 多次反查無需重新激活
   - **切換** — 在反查和輸入法間切換

### 反查結果排序

1. 進入 **喜好設定** → **反查設定** → **結果排序**
2. 選擇：
   - **頻率順** — 按使用頻率排列
   - **筆劃順** — 按筆劃數排列
   - **部首順** — 按部首排列

## 常見問題

### Q: 反查無法啟動

**A:** 檢查以下：

1. **功能已啟用？** 進入 **喜好設定** → **反查** → 確認啟用
2. **快捷鍵正確？** 試試不同快捷鍵
3. **輸入法支援？** 不是所有輸入法都支援反查

### Q: 反查結果太多，難以找到

**A:** 嘗試：

1. **輸入更多符號** — 縮小搜尋範圍
2. **改變結果排序** — 改為「頻率順」快速找常用字
3. **使用筆劃數** — 結合筆劃反查精確搜尋

### Q: 反查後無法回到正常輸入

**A:** 可能原因：

1. **反查模式設為「持續」** — 改為「單次」
2. **手動切換回輸入法** — 按相應快捷鍵切換

### Q: iOS 上反查無法使用

**A:** iOS 的反查功能有限制。嘗試：

1. 確認已在 **喜好設定** 中啟用反查
2. 某些 iOS 版本可能不支援，建議升級 LIME 版本

## 進階用法

### 組合反查

某些輸入法支援多種反查方式，可組合使用：

```
不確定字的注音 → 用筆劃反查
筆劃反查結果太多 → 再用注音精確搜尋
```

## 何時使用反查

### 常見場景

1. **忘記編碼** — 知道字但不知道怎麼打
2. **學習新輸入法** — 學習階段快速查詢
3. **輸入特殊字符** — 罕見字或異體字
4. **驗證編碼** — 確認自己記得的編碼對不對
