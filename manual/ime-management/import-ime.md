# 匯入輸入法

手動匯入自訂或特殊輸入法檔案。

## 支援的檔案格式

| 格式 | 副檔名 | 說明 |
|------|------|------|
| CIN (Chewing Input) | `.cin` | 通用格式，包含字根和候選字 |
| LIME 資料庫 | `.limedb` | LIME 專用格式 |
| LIME 輸入法 | `.lime` | LIME 專用壓縮格式 |

## 如何匯入

### Android

1. 準備輸入法檔案：
   - 從網路下載 `.cin`、`.limedb` 或 `.lime` 檔案
   - 或從其他裝置複製檔案
   - 檔案應儲存在可存取的位置（例如 **下載資料夾**）

2. 開啟 **萱姆輸入法** 應用

3. 進入 **輸入法管理** → **匯入輸入法**

4. 選擇檔案：
   - 系統會開啟檔案管理器
   - 瀏覽並找到你的輸入法檔案
   - 點選選擇

5. 等待匯入完成，輸入法會新增到列表

### iOS & iPad

1. 準備輸入法檔案

2. 開啟 **萱姆輸入法** 應用

3. 進入 **輸入法管理** → **+ 匯入** 或 **匯入輸入法**

4. 選擇檔案：
   - 可從 iCloud Drive、檔案應用或透過郵件附件選擇
   - 點選檔案確認

5. 匯入完成後，輸入法可立即使用

## 獲取輸入法檔案

### 官方來源

- [LIME IME GitHub 倉庫](https://github.com/lime-ime/limeime) — 官方提供的輸入法
- 預裝輸入法（注音、倉頡等）

### 社群來源

- [Chewing 計畫](https://chewing.im/) — 多種開源輸入法
- [RIME 輸入法](https://rime.im/) — 可轉換為 .cin 格式
- 其他開源輸入法社群

> **安全提示：** 只從信任的來源下載輸入法檔案。

## 常見問題

### 「無法讀取檔案」

**症狀：** 匯入時出現此錯誤

**可能原因：**

1. 檔案格式不支援（僅支援 `.cin`、`.limedb`、`.lime`）
2. 檔案已損壞或不完整
3. 檔案編碼問題

**解決方案：**

1. 確認檔案副檔名正確
2. 重新下載檔案（原始下載可能損壞）
3. 嘗試從其他來源獲取

### 「檔案不存在」

**症狀：** 找不到檔案或選擇後出現此錯誤

**解決方案：**

1. 確認檔案已儲存在可存取位置
2. 嘗試移動檔案到更明顯的位置（例如下載資料夾）
3. 檢查檔案權限（某些應用可能限制存取）

### 匯入後無法使用

**症狀：** 輸入法已匯入但無法在鍵盤上使用

**解決方案：**

1. 重啟應用
2. 檢查輸入法是否已啟用：
   - Android：進入 **系統設定** → **語言與輸入法** 啟用
   - iOS：進入 **設定** → **鍵盤** 確認已新增

3. 重啟手機

### .cin 檔案無法匯入

**症狀：** .cin 檔案拒絕匯入

**可能原因：**

1. 檔案編碼不是 UTF-8
2. 檔案格式不符合 CIN 標準
3. 檔案內容不完整

**解決方案：**

1. 檢查檔案編碼（應為 UTF-8）
2. 用文字編輯器開啟檔案，確認內容有效
3. 從官方來源重新下載

## 備份與復原

匯入的輸入法會自動儲存在 LIME 的資料庫中。

- **備份：** 進入 **設定** → **備份與還原** 匯出所有資料
- **復原：** 匯入備份檔案恢復輸入法和設定

詳見 [備份與還原](../preferences/backup-restore.md)。
