# 編輯與自訂輸入法

自訂輸入法的字根、詞句與相關字。

## 功能概述

萱姆輸入法編輯器可以：

1. **編輯字根** — 新增、修改或刪除字根映射
2. **新增詞句** — 建立常用詞彙快速輸入
3. **相關字詞** — 為常用字新增相關詞句
4. **導入/導出** — 與他人共享自訂資料

> **提示：** 編輯功能最適合進階使用者。初學者建議先熟悉基本輸入法後再使用。

## 如何進入編輯器

### Android

1. 開啟 **萱姆輸入法** 應用
2. 進入 **輸入法管理**
3. 找到要編輯的輸入法
4. 點選 **編輯** 或 **管理**

### iOS & iPad

1. 開啟 **萱姆輸入法** 應用
2. 進入 **輸入法管理** → 選擇輸入法
3. 點選 **編輯** 或 **⚙ 設定**

## 編輯字根

### 新增字根

1. 在編輯器中選擇 **新增字根** 或 **+ 字根**
2. 輸入：
   - **編碼**：輸入法編碼（例如 「ㄓㄨㄥ」 或 「nok」）
   - **字符**：實際字符（例如 「中」）
3. 點選 **確認** 或 **保存**

### 修改現有字根

1. 在列表中找到字根
2. 點選編輯圖示或長按
3. 修改編碼或字符
4. 保存

### 刪除字根

1. 長按或滑動字根
2. 點選 **刪除**

> **警告：** 刪除字根後無法撤銷。建議先備份。

## 新增詞句

### 新增常用詞

1. 選擇 **新增詞句** 或 **+ 詞**
2. 輸入：
   - **詞語**：完整詞句（例如 「輸入法」）
   - **編碼**：快速編碼（例如 「ㄕㄨ」）
3. 保存

### 設定詞語優先度

在候選列中優先顯示常用詞：

1. 編輯詞語
2. 設定 **優先度** 或 **頻率**
3. 更高數值 = 更優先顯示

## 相關字詞

為常用字新增相關詞彙。例如：

- 字 「好」 的相關詞：「很好」、「好吧」、「好的」
- 字 「中」 的相關詞：「中文」、「中國」、「中午」

### 新增相關字詞

1. 選擇 **相關字詞** 或 **相關詞**
2. 選擇要新增的字（例如 「好」）
3. 新增相關詞句
4. 設定優先度
5. 保存

## 導入/導出

### 導出自訂資料

1. 選擇 **導出** 或 **備份**
2. 選擇導出範圍：
   - 字根只
   - 詞句只
   - 全部
3. 選擇檔案位置
4. 確認保存

**用途：** 備份自訂資料或在其他裝置上使用。

### 導入自訂資料

1. 選擇 **導入** 或 **還原**
2. 選擇導入檔案
3. 選擇導入範圍（合併或覆蓋）
4. 確認匯入

**用途：** 從備份還原或使用他人共享的自訂資料。

## 最佳實踐

### 定期備份

1. 定期導出自訂資料
2. 儲存到安全位置（雲端、電腦）
3. 避免自訂資料丟失

### 循序漸進編輯

1. 先使用內建輸入法習慣基本操作
2. 再新增常用詞句加快速度
3. 進階後才編輯字根

### 避免過度自訂

- 不要新增太多自訂字根，容易混淆
- 詞句優先度要合理設定
- 定期檢查自訂資料是否有用

## 常見問題

### Q: 如何復原編輯？

**A:** 無法直接復原。建議：

1. 定期備份自訂資料
2. 如編輯有誤，可從備份還原

### Q: 自訂資料會同步到其他裝置嗎？

**A:** 不會自動同步。需手動導出後在其他裝置導入。

### Q: 新增詞句後為什麼沒出現在候選列？

**A:** 可能原因：

1. 編碼錯誤 — 檢查輸入的編碼
2. 詞語已存在 — 系統可能已有該詞
3. 優先度太低 — 提高優先度

### Q: 可以編輯官方輸入法嗎？

**A:** 可以，但建議：

1. 先備份原始輸入法
2. 複製一份後編輯副本
3. 避免破壞官方版本
