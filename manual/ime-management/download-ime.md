# 下載輸入法

從萱姆輸入法應用內下載官方支援的輸入法。

## 支援的輸入法列表

萱姆支援以下輸入法（排序依推薦順序）：

- **注音（標準）** — 台灣最常用
- **注音（臺羅）** — 台羅符號版本
- **倉頡（第五版）** — 香港、大陸常用
- **倉頡（第三版）** — 舊版倉頡
- **大易** — 快速輸入法
- **嘸蟲蛇** — 形音混合
- **其他** — 見 [所有支援的輸入法](ime-list.md)

詳細介紹見 [輸入法列表](ime-list.md)。

## 如何下載

### Android

1. 開啟 **萱姆輸入法** 應用
2. 進入 **輸入法管理** 或 **Settings** → **輸入法列表**
3. 點選 **+ 下載新輸入法** 或 **新增**
4. 瀏覽列表並選擇想要的輸入法（例如 **注音**）
5. 點選 **下載** 開始下載
6. 等待完成後，該輸入法會出現在你的輸入法列表

### iOS & iPad

1. 開啟 **萱姆輸入法** 應用
2. 進入 **輸入法管理** 或 **Settings**
3. 點選 **下載輸入法** 或 **+ 新增**
4. 選擇輸入法
5. 點選 **下載**
6. 返回主畫面，新輸入法已可用

> **提示：** iOS 上下載的輸入法對應用內和系統鍵盤都有效。

## 下載要求

- **網路連線：** 需要 WiFi 或行動網路
- **儲存空間：** 每個輸入法通常 1–5 MB
- **帳戶：** 無需帳戶或登入

## 下載失敗排查

### 無法連線

**症狀：** 下載時出現「無法連線」或「網路錯誤」

**解決方案：**

1. 檢查網路連線
2. 嘗試切換 WiFi 或行動網路
3. 重啟應用後重試
4. 如持續失敗，改用 [手動匯入](import-ime.md)

### 下載中斷

**症狀：** 下載進行中突然停止

**解決方案：**

1. 檢查網路是否穩定
2. 重啟應用
3. 重新下載

### 下載後無法使用

**症狀：** 下載完成後輸入法不出現在列表

**解決方案：**

1. 重啟應用
2. 進入輸入法管理檢查是否已列出
3. 如仍未出現，嘗試 [手動匯入](import-ime.md)

## 管理已下載的輸入法

### 刪除輸入法

1. 進入 **輸入法管理**
2. 長按或滑動輸入法名稱
3. 點選 **刪除** 或 **移除**

> **提示：** 刪除輸入法不會影響其他輸入法，也不會影響儲存的學習資料。

### 設定預設輸入法

1. 進入 **輸入法管理**
2. 長按輸入法並選擇 **設定為預設**
3. 或在輸入法列表中選擇想要的輸入法
