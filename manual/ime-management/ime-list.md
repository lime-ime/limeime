# 所有支援的輸入法

萱姆輸入法支援多種中文輸入法。本頁列出所有支援的輸入法、學習曲線與適用地區。

## 按推薦順序

### 1. 注音 (Zhuyin / Bopomofo)

| 屬性 | 說明 |
|------|------|
| **使用地區** | 🇹🇼 台灣（最常見） |
| **學習難度** | ⭐ 極容易 |
| **輸入速度** | ⭐⭐ 中等 |
| **使用者群** | 台灣大多數使用者 |

**介紹：** 注音是台灣最常用的輸入法。每個中文字對應一個注音符號組合（ㄓ ㄨ ㄥ 等）。

**範例：**
```
ㄒ ㄧ ˇ = 西
ㄐ ㄧ ㄥ ˊ = 靖
```

**優點：**
- 容易學習，台灣小學即教
- 直觀對應發音
- 適合初學者

**缺點：**
- 輸入速度較慢（相比倉頡、大易）

---

### 2. 倉頡 (Cangjie)

| 屬性 | 說明 |
|------|------|
| **使用地區** | 🇭🇰 香港、🇨🇳 大陸常用 |
| **學習難度** | ⭐⭐⭐ 中等 |
| **輸入速度** | ⭐⭐⭐ 快 |
| **使用者群** | 港澳、大陸、海外華人 |

**介紹：** 倉頡是筆劃組合輸入法。每個字由筆劃根部構成。

**範例：**
```
手 (nok) = 人手十
靖 (gipf) = 一女十日十
```

**優點：**
- 輸入速度快
- 香港、大陸常用
- 筆劃邏輯清晰

**缺點：**
- 需要學習筆劃根部（約 25 個基本根）
- 初期較難上手

**版本：** 支援倉頡第三版與第五版

---

### 3. 大易 (Dayi)

| 屬性 | 說明 |
|------|------|
| **使用地區** | 全球華人進階使用者 |
| **學習難度** | ⭐⭐⭐⭐ 較難 |
| **輸入速度** | ⭐⭐⭐⭐⭐ 極快 |
| **使用者群** | 專業打字員、編輯 |

**介紹：** 大易是快速編碼輸入法。設計目標是最高輸入速度。

**優點：**
- 輸入速度極快（可達倉頡 2 倍）
- 編碼短（大多 2–3 鍵）
- 專業級輸入法

**缺點：**
- 編碼需要死記，無規律
- 學習曲線陡峭
- 不適合業餘使用者

---

### 4. 嘸蟲蛇 (Boshiamy / Bopomo)

| 屬性 | 說明 |
|------|------|
| **使用地區** | 台灣、海外華人 |
| **學習難度** | ⭐⭐⭐ 中等 |
| **輸入速度** | ⭐⭐⭐ 快 |
| **使用者群** | 台灣特定愛好者 |

**介紹：** 嘸蟲蛇是形音混合輸入法，結合筆劃與注音。

**優點：**
- 快於注音，慢於倉頡
- 台灣開發，在地化強
- 筆劃 + 注音雙重索引

**缺點：**
- 使用者較少
- 資源較少

---

## 其他支援的輸入法

### 鄭碼 (Zhengma)

- **地區：** 中文社群
- **特點：** 形編碼，筆劃邏輯清晰
- **學習難度：** ⭐⭐⭐ 中等

### 五筆 (Wubi)

- **地區：** 大陸常用
- **特點：** 筆劃編碼
- **學習難度：** ⭐⭐⭐ 中等

### 雙拼 (Shuangpin)

- **地區：** 拼音入門
- **特點：** 簡化拼音
- **學習難度：** ⭐ 極容易（如果懂拼音）

## 如何選擇

### 如果你在台灣
**推薦：注音 → 倉頡**

注音是台灣標配。進階後可學倉頡加快速度。

### 如果你在香港或大陸
**推薦：倉頡 → 鄭碼或五筆**

倉頡是香港標配。大陸使用者可選擇本地化輸入法。

### 如果你想最快速度
**推薦：大易**

大易是速度之王，但學習最陡。

### 如果你是初學者
**推薦：注音**

注音最易學，對初學者最友善。

### 如果你用 iOS
**推薦：注音或倉頡**

iOS 上注音和倉頡最穩定。
