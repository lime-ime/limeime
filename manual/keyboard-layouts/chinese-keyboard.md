# 中文鍵盤

中文鍵盤用於輸入中文字符。佈局根據所選輸入法而異。

## 中文鍵盤基本佈局

中文鍵盤的按鍵對應輸入法編碼：

### 注音鍵盤

```
ㄅ ㄆ ㄇ ㄈ ㄉ ㄊ ㄋ ㄌ
ㄍ ㄎ ㄏ ㄐ ㄑ ㄒ ㄓ ㄔ ㄕ
ㄖ ㄗ ㄘ ㄙ ㄚ ㄛ ㄜ ㄝ
```

### 倉頡鍵盤

```
Q W E R T Y U I O P
A S D F G H J K L
Z X C V B N M
```

（與英文鍵盤相同，但字母映射到倉頡筆劃根）

### 大易鍵盤

```
根據大易編碼分佈
（詳見輸入法說明）
```

## 候選列

在中文鍵盤上輸入時，候選字會在鍵盤上方顯示：

```
┌─────────────────────────────────┐
│ 你 他 我 在 於 ...   [Page Down] │
│ 1  2  3  4  5        ▶           │
└─────────────────────────────────┘
```

### 選擇候選字

**方法 1：按數字鍵**

按 **1–9** 選擇候選列中的字（第 1 至 9 個）

**方法 2：點選候選字**

直接點選鍵盤上方的候選字

**方法 3：滑動候選列**

向左滑動候選列查看更多選項，向右滑動返回

## 特殊鍵

中文鍵盤上的特殊鍵：

| 鍵 | 功能 |
|----|------|
| **EN / ABC** | 切換到英文模式 |
| **123** | 切換到數字符號鍵盤 |
| **中 / CN** | 返回中文選擇（某些輸入法） |
| **空白鍵** | 選擇首個候選字並輸入 |
| **刪除 / ⌫** | 刪除已輸入編碼的最後一個按鍵 |

## 長按彈出迷你鍵盤

在中文鍵盤長按某些按鍵可輸入相關符號。

詳見 [長按功能](popup-keyboards.md)。

## 候選列操作

### 分頁瀏覽

如果候選字超過 9 個：

1. 按右上角的 **[Page Down]** 或 **▶** 瀏覽下一頁
2. 按 **[Page Up]** 或 **◀** 返回上一頁
3. 或向左滑動候選列

### 搜尋候選字

在某些輸入法中，可以繼續輸入編碼以縮小候選字：

```
輸入 ㄓ → 候選：這 中 之 ...
繼續輸入 ㄥ → 候選：中 正 ...
```

### 快速選擇

按空白鍵直接選擇首個候選字：

```
輸入 ㄓ ㄥ → 首選通常是「中」
按空白鍵 → 「中」被輸入
```

## 自動學習

萱姆輸入法會學習你的輸入習慣：

- 常用的字會自動上升到首位
- 詞句組合會被記住
- 個人用語可被添加到使用者字典

詳見 [學習系統](../advanced/learning-system.md)。

## 重複輸入

有時需要輸入同一個字多次（如「哈哈哈」）：

**方法 1：重複選擇**
```
輸入 ㄏ ㄚ → 選「哈」
再輸入 ㄏ ㄚ → 選「哈」
```

**方法 2：快速重複**

某些輸入法支援按候選字旁的 **+** 或 **重複** 按鈕。

## 平台差異

### Android

- 完整鍵盤自訂選項
- 支援滑動翻頁
- 可自訂候選列大小

### iOS & iPad

- 鍵盤主要由系統控制
- 候選列由 LIME 提供
- iPad 支援分割鍵盤

詳見 [iPad 副鍵符號](ipad/secondary-glyphs.md)。

## 輸入法間的差異

不同輸入法的鍵盤佈局不同：

| 輸入法 | 鍵盤 | 特點 |
|------|------|------|
| 注音 | 注音符號 | 直觀，對應發音 |
| 倉頡 | 英文 QWERTY | 需學習筆劃根 |
| 大易 | 英文 QWERTY | 編碼無規律 |

詳見 [所有支援的輸入法](../ime-management/ime-list.md)。
