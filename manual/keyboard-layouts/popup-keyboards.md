# 長按功能與迷你鍵盤

長按鍵盤按鍵以快速訪問符號與特殊字符。

## 什麼是迷你鍵盤？

迷你鍵盤是長按某個鍵時彈出的小鍵盤，顯示相關的符號或字符。

```
長按「。」鍵
↓
┌─────────────┐
│ , ; : ‥ … │
│ 1 2 3 4  5 │
└─────────────┘
```

選擇符號後，該符號被輸入到文字欄中。

## 長按規則

### 長按的觸發條件

1. **按住鍵** — 按下並保持 0.5–1 秒
2. **迷你鍵盤彈出** — 鍵盤上方顯示相關符號
3. **滑動選擇** — 滑動到想要的符號
4. **鬆開** — 鬆開手指輸入選中的符號

### 取消長按

如果不想選擇：

1. 向下滑動後離開符號區域
2. 按返回鍵
3. 輕輕點擊（不是長按）

## 常見長按符號

### 中文鍵盤

| 原按鍵 | 長按結果 |
|------|--------|
| **。** | ， ; : ‥ … |
| **、** | ‥ … |
| **！** | ¡（倒驚嘆號） |
| **？** | ¿（倒問號） |

### 英文鍵盤

| 原按鍵 | 長按結果 |
|------|--------|
| **.** | , ; : … |
| **/** | \ |
| **0** | ) |
| **9** | ( |
| **A** | À Á Â Ã Ä Å（帶音符） |
| **E** | È É Ê Ë（帶音符） |

### 數字符號鍵盤

| 原按鍵 | 長按結果 |
|------|--------|
| **1** | ¹ ½ ⅓ ⅛ |
| **2** | ² |
| **3** | ³ ⅓ |
| **4** | ⁴ ¼ |
| **5** | ⁵ ⅗ |

## 平台差異

### Android

- **控制：** LIME 全面控制迷你鍵盤
- **自訂：** 可在設定中自訂長按符號
- **靈敏度：** 可調整長按時間

進入 **設定** → **輸入行為** → **長按時間** 調整靈敏度。

### iOS & iPad

- **控制：** 由系統與 LIME 共同控制
- **限制：** 某些符號由系統決定
- **自訂：** 有限自訂選項

## 迷你鍵盤操作

### 選擇符號

**方法 1：滑動選擇**

```
長按「。」
    ↓
選擇「，」
    ↓
向右滑動至「，」位置
    ↓
鬆開 → 「，」被輸入
```

**方法 2：數字鍵選擇**

某些迷你鍵盤支援按數字選擇：

```
長按「。」
    ↓
按「2」選擇第 2 個符號（；）
    ↓
「；」被輸入
```

### 取消選擇

向下拖動至符號區域外，然後鬆開。

## 高級功能

### 音符與重音字符

長按支持帶重音的字符（用於外文）：

```
長按「A」
    ↓
À Á Â Ã Ä Å
```

### 加倍字符

某些輸入法支援長按以加倍字符：

```
長按「A」並繼續按住
    ↓
AA（多重選擇）
```

## 長按無反應

### 問題排查

如果長按無反應：

1. **檢查時間** — 確保按住足夠長（通常 0.5 秒）
2. **檢查設定** — 某些設定可能禁用了長按
   - Android：**設定** → **輸入行為** → **啟用長按**
3. **檢查鍵盤主題** — 某些主題可能不支援迷你鍵盤
4. **重啟應用** — 有時需要重新啟動

### 長按時間調整

在 LIME 設定中調整長按靈敏度（Android）：

1. 開啟 LIME 應用
2. 進入 **設定** → **輸入行為** → **長按時間**
3. 選擇：
   - **短** — 快速觸發
   - **正常** — 標準設置
   - **長** — 需要更久的按住時間

## 迷你鍵盤提示

1. **精準選擇** — 滑動時盡量準確，避免誤選
2. **自訂常用** — 如常用某些符號，可自訂長按符號
3. **實踐** — 練習長按直到成為習慣
