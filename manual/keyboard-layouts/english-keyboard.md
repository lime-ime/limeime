# 英文鍵盤

萱姆的英文鍵盤佈局與使用說明。

## 英文鍵盤佈局

英文鍵盤用於輸入英文字母、數字與標點符號。

### 標準佈局

```
Q W E R T Y U I O P
A S D F G H J K L
Z X C V B N M
```

加上以下特殊鍵：

| 位置 | 鍵 | 功能 |
|------|-----|------|
| 左上 | **ABC** | 英文模式指示 |
| 底部左 | **CN** 或 **中** | 切換到中文輸入 |
| 底部中 | **空白鍵** | 空格 |
| 底部右 | **123** | 切換到數字鍵盤 |
| 右上 | **刪除** / **⌫** | 刪除前一字 |

### 數字與符號

按 **123** 鍵切換到數字鍵盤：

```
1 2 3 4 5 6 7 8 9 0
@ # $ % ^ & * + - =
```

常用符號：

| 符號 | 如何輸入 |
|------|--------|
| `.` (句號) | 按 **.** 鍵 |
| `,` (逗號) | 按 **,** 鍵 |
| `?` (問號) | 按 **?** 鍵 |
| `!` (驚嘆號) | 按 **!** 鍵 |
| `'` (單引號) | 按 **'** 鍵 |
| `"` (雙引號) | 按 **"** 鍵 |

## 快速切換

### 切換到英文模式

在中文輸入時，有幾種方式切換到英文：

1. **按 EN 鍵**（如果可見）
2. **按空白鍵** — 某些輸入法支援
3. **搖動裝置** — 某些手機支援
4. **長按空白鍵** — 部分裝置支援

### 切換回中文模式

在英文模式按 **中** 或 **CN** 鍵，或按輸入法切換。

## 長按符號

在英文鍵盤上長按某些按鍵可輸入符號：

| 按鍵 | 長按結果 |
|-----|--------|
| **.** | `,` `;` `:` `…` |
| **/** | `\` |
| **0** | `)` |
| **9** | `(` |

> **提示：** 具體長按符號取決於裝置與鍵盤主題。

## 移動光標

某些裝置支援以下方式移動光標：

- **向左滑動** — 移動光標向左
- **向右滑動** — 移動光標向右
- **上下滑動** — 選擇前後字符

> **提示：** 光標移動功能需在 **喜好設定** → **輸入行為** 中啟用。

## 複製與貼上

### 複製文字

1. 在應用中長按文字
2. 選擇 **複製**

### 貼上文字

1. 在輸入欄位長按
2. 選擇 **貼上**

> **提示：** 複製貼上功能由應用提供，不由 LIME 控制。

## 鍵盤主題

英文鍵盤的外觀可自訂：

1. 開啟 LIME 應用 → **喜好設定** → **外觀**
2. 選擇 **鍵盤主題**（深色、淺色、彩色等）
3. 調整 **字體大小**、**按鍵間距** 等

## 平台差異

### Android

- 支援全鍵盤自訂
- 支援滑動輸入（部分機型）
- 可關閉長按符號

### iOS & iPad

- 長按符號由系統控制
- iPad 支援分割鍵盤模式
- 支援多觸點手勢

詳見 [iPad 副鍵符號](ipad/secondary-glyphs.md)。
