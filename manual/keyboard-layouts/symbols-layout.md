# 符號頁面

快速輸入中文與英文符號。

## 符號鍵盤

按鍵盤上的 **123** 或 **符號** 鍵進入符號鍵盤。

### 符號分類

符號鍵盤通常分為多個頁面：

#### 第 1 頁：基本符號

```
1  2  3  4  5  6  7  8  9  0
@  #  $  %  ^  &  *  +  -  =
.  ,  ?  !  '  "  :  ;  /  \
```

#### 第 2 頁：中文標點

```
。 、 ， ； ： ？ ！ … ·
「 」 『 』 （ ） 《 》
```

#### 第 3 頁：貨幣與數學符號

```
¥  €  £  ¢  ©  ®  ™
+  -  ×  ÷  =  <  >
```

#### 第 4 頁：特殊符號

```
♠  ♥  ♦  ♣  ★  ☆
→  ← ↑  ↓  ◆  ○
```

> **提示：** 具體符號頁面因手機和主題而異。

## 快速輸入常見符號

### 中文標點

| 符號 | 說明 | 輸入方式 |
|------|------|--------|
| **。** | 句號 | 123 → 句號 |
| **、** | 頓號 | 123 → 頓號 |
| **，** | 逗號 | 123 → 逗號 |
| **；** | 分號 | 123 → 分號 |
| **：** | 冒號 | 123 → 冒號 |
| **？** | 問號 | 123 → 問號 |
| **！** | 驚嘆號 | 123 → 驚嘆號 |
| **「」** | 左右引號 | 123 → 「」 |
| **『』** | 二重引號 | 123 → 『』 |
| **…** | 省略號 | 123 → … |

### 英文符號

| 符號 | 說明 | 輸入方式 |
|------|------|--------|
| **.** | 句號 | 123 → . |
| **,** | 逗號 | 123 → , |
| **?** | 問號 | 123 → ? |
| **!** | 驚嘆號 | 123 → ! |
| **;** | 分號 | 123 → ; |
| **:** | 冒號 | 123 → : |
| **'** | 單引號 | 123 → ' |
| **"** | 雙引號 | 123 → " |

## 快捷方式

### 從中文輸入直接輸入符號

某些輸入法支援快速符號輸入：

1. **長按空白鍵** — 快速選擇符號
2. **按特定組合鍵** — 例如 Shift + 某鍵（部分輸入法）

### 從英文模式輸入

在英文模式中按 **123** 可進入數字與符號鍵盤。

## 數字與數字符號

### 阿拉伯數字

```
1 2 3 4 5 6 7 8 9 0
```

### 中文數字

某些符號頁面包含中文數字：

```
零 一 二 三 四 五 六 七 八 九 十 百 千 萬
```

快速輸入：按 **123** → 翻頁至中文數字區

## 特殊符號技巧

### 長按符號鍵

長按某些符號鍵可輸入相關符號：

| 按鍵 | 長按結果 |
|------|--------|
| **?** | ¿ （倒問號） |
| **!** | ¡ （倒驚嘆號） |
| **.** | … ; , : |

### 重複輸入符號

按空白鍵或 + 鍵可重複輸入同一符號：

```
輸入點點點：... 或 。。。
```

## 符號翻頁

### 翻頁方式

1. **按右上角的 ▶ 按鈕** — 進入下一頁
2. **向左滑動** — 快速進入下一頁
3. **按 Page Down** — 分頁瀏覽

### 返回上一頁

1. **按左上角的 ◀ 按鈕**
2. **向右滑動**
3. **按 Page Up**
