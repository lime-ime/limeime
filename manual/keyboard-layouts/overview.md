# 鍵盤佈局

本章節說明萱姆輸入法的鍵盤佈局、特殊鍵、與手勢操作。

## 本章主題

1. **[概述](overview.md)** — 鍵盤佈局簡介
2. **[英文鍵盤](english-keyboard.md)** — 英文輸入模式佈局
3. **[中文鍵盤](chinese-keyboard.md)** — 中文輸入模式、候選列
4. **[符號頁面](symbols-layout.md)** — 快速輸入符號與標點

## 鍵盤模式

- **英文鍵盤** — 輸入英文、數字、標點符號
- **中文鍵盤** — 輸入中文、候選列顯示、快速模式切換
- **符號鍵盤** — 快速存取標點符號

## 特殊功能

- 長按鍵盤按鍵以存取額外符號
- iPad 上的副鍵符號與多點觸控手勢
- 自訂快速鍵與特殊按鍵
