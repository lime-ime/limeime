# iPad 副鍵符號

iPad 上的獨特鍵盤功能——副鍵符號與多點觸控手勢。

> **平台限制：** 此功能僅在 iPad 上可用。iPhone 用戶詳見 [長按功能](../popup-keyboards.md)。

## 什麼是副鍵符號？

在 iPad 上，某些鍵的右上角會顯示一個小符號——**副鍵符號**。這是 iPad 特有的功能，用於快速訪問相關符號。

```
鍵顯示
  ┌──┐
  │ .   ← 副鍵符號（,）
  └──┘
```

## 如何使用副鍵符號

### 方法 1：輕掃（Swipe）

1. 輕輕觸碰按鍵
2. **向上輕掃** — 輸入副鍵符號
3. 鬆開

```
按「。」鍵
    ↓
向上輕掃
    ↓
「，」被輸入（副鍵符號）
```

### 方法 2：長按

1. **長按按鍵** — 顯示符號選單
2. **滑動選擇** — 選擇想要的符號
3. **鬆開** — 輸入符號

### 方法 3：快速按住後向上拖動

1. 按住按鍵
2. 向上拖動至副鍵符號
3. 鬆開

## iPad 鍵盤佈局

### 標準 iPad 佈局

iPad 的鍵盤比 iPhone 寬敞，按鍵更大，更容易輕掃副鍵符號。

```
Q W E R T Y U I O P
  ▲副鍵符號示意
  
A S D F G H J K L
Z X C V B N M
```

### 分割鍵盤模式

在分割鍵盤模式中，鍵盤分成左右兩側：

```
Q W E R T  Y U I O P
A S D F G  H J K L
Z X C V B  N M
```

副鍵符號在分割模式下仍可用。

## 常見 iPad 副鍵符號

| 按鍵 | 副鍵符號 | 說明 |
|------|--------|------|
| **A** | À | 帶重音的 A |
| **E** | È | 帶重音的 E |
| **I** | Ì | 帶重音的 I |
| **O** | Ò | 帶重音的 O |
| **U** | Ù | 帶重音的 U |

| **-** | **—** | 破折號 |

## 分割鍵盤（Split Keyboard）

### 啟用分割鍵盤

1. 在 iPad 上開啟任何輸入欄
2. 喚出 LIME 鍵盤
3. 進入 LIME 設定 → **喜好設定** → **鍵盤** → **分割鍵盤**
4. 開啟 **分割鍵盤模式**

### 分割鍵盤優點

- **單手輸入** — 兩隻大拇指各控制一側
- **自然姿勢** — 更符合自然握持姿勢
- **更寬敞** — 按鍵更大，精準度更高

### 分割鍵盤缺點

- **佔用空間** — 應用視窗被壓縮
- **不適合快速打字** — 相比全寬鍵盤稍慢

## 多點觸控手勢

iPad 鍵盤支援多點觸控手勢：

### 兩根手指滑動

在候選列上用兩根手指向左滑動 → 快速翻頁

### 三根手指點擊

在某些 iPad 機型上可用於特殊操作（依 iPadOS 版本而異）

## iPad 特定設定

### 鍵盤大小

1. 進入 LIME 設定
2. **喜好設定** → **外觀** → **鍵盤大小**
3. 選擇：
   - **小** — 節省空間
   - **正常** — 標準大小
   - **大** — 更容易按

### 副鍵符號靈敏度

1. 進入 LIME 設定
2. **喜好設定** → **輸入行為** → **副鍵靈敏度**
3. 調整輕掃靈敏度

## 常見問題

### Q: 副鍵符號無法使用

**A:** 檢查以下：

1. 確認已在 iPad 上（iPhone 不支援）
2. 檢查 LIME 版本是否為最新
3. 嘗試重新啟動 LIME 應用

### Q: 輕掃無法觸發副鍵符號

**A:** 可能原因：

1. **輕掃角度不對** — 確保向上輕掃（不是向下或向旁邊）
2. **輕掃速度過快** — 慢下來，確保足夠的接觸時間
3. **靈敏度太高** — 在設定中降低靈敏度

### Q: 分割鍵盤模式下副鍵符號不工作

**A:** 分割鍵盤模式下副鍵符號可能表現不同。嘗試：

1. 調整 **副鍵靈敏度** 設定
2. 使用 **長按** 替代輕掃
3. 重試幾次直到習慣
