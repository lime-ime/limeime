# 備份與還原

「資料庫」分頁可把整個輸入法資料庫（含碼表與學習記錄）打包備份，並在需要時還原，換新機、重灌或想保存學習成果時都用得到。備份會把所有已安裝的輸入法、關聯字庫與學習記錄一起打包，是換機轉移最完整的方式。

## 備份資料庫

1. **開啟「資料庫」分頁**點按底部的「資料庫」分頁。

2. **點按「備份資料庫」**系統開始打包，大型資料庫可能需要數秒，畫面會顯示進度。

3. **儲存備份檔**打包完成後會出現分享畫面，可存到「檔案」、雲端硬碟或以 AirDrop 等方式傳送 `.zip` 備份檔。

## 還原資料庫

1. **點按「還原資料庫」**畫面會先跳出確認提示，「還原後目前所有資料將被取代，確定繼續？」。

2. **選擇備份檔**確認後選取先前的 `.zip` 或 `.limedb` 備份檔。

3. **等待完成**還原完成後，輸入法清單與關聯字會自動重新整理，畫面顯示「資料庫還原完成」。

> **還原會覆蓋目前所有資料**還原後，裝置上目前的萊姆輸入法資料會被備份檔完全取代且無法復原。換機時建議在尚未輸入大量內容前先完成還原，若擔心，可先用「備份資料庫」保存目前狀態。

## 還原預設資料庫

若資料庫出現異常，可選擇還原為預設資料庫，回到初始狀態後再重新下載需要的輸入法。此操作同樣會覆蓋現有資料，請先評估是否需要先備份。

## 舊版備份與其他入口

部分舊版萊姆輸入法或特定機型（例如某些 Samsung 裝置）的備份入口位置可能不同。若你持有舊版備份，仍可透過「還原資料庫」選取舊備份檔進行還原。

> **還原前先確認來源**還原舊版備份前，請確認檔案來源可信，避免覆蓋現有資料後才發現備份不完整。
